# Movie App 🎬

A simple movie search application built using HTML, CSS, and JavaScript.  
The app fetches movie data from the OMDb API and displays movie posters, titles, ratings, and release years in a clean interface.

## Features

- Search for movies in real time
- Display movie posters and details
- Responsive design
- Watch later functionality using local storage
- Dynamic movie rendering with JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- OMDb API
